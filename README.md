# App Builder

## Overview

This repository contains a Claude skill for app building. It provides a structured workflow for turning an application idea into a clear plan and actionable implementation guidance.

## What It Covers

- Clarifying the app's purpose and target users.
- Defining core features and requirements.
- Organizing implementation priorities.
- Reviewing product and technical trade-offs.

## Getting Started

1. Review `SKILL.md` to understand the skill's workflow.
2. Install the skill in the skills directory supported by your Claude environment.
3. Describe the app idea, target audience, constraints, and desired outcome.
4. Use the workflow to shape requirements and implementation steps.
5. Validate the plan against available time, resources, and technical constraints.

## Practical Note

Keep the first release narrow. Prioritize a usable core workflow over a long feature list, and validate assumptions with real users before expanding scope.
