# Project Scaffolding

Create only the structure needed for the selected architecture.

## Initial setup
1. Confirm the repository is empty or understand existing conventions.
2. Create the package/build configuration and entry points.
3. Add environment example files without real secrets.
4. Add formatting, linting, type-checking, and tests where relevant.
5. Add health/readiness or basic runtime checks for services.
6. Document install, run, test, build, and deployment commands.

## Safety
Never overwrite an existing project without inspecting it. Preserve user code and configuration. Use lockfiles and the package manager already established by the repository.

## Completion
Run install, lint, type-check, tests, and production build when supported. Report skipped checks and their reasons.
