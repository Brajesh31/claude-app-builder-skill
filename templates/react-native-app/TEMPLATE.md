# React Native Application Template

Use for iOS and Android apps sharing a React Native codebase.

## Structure
- `src/screens/`: navigation screens
- `src/components/`: reusable UI
- `src/navigation/`: route configuration
- `src/services/`: API and device integrations
- `src/state/`: app state
- `src/theme/`: tokens and styling
- `tests/`: component and flow tests

Define offline behavior, secure token storage, permission handling, accessibility, platform-specific differences, and crash reporting. Test on both platforms and multiple screen sizes.
