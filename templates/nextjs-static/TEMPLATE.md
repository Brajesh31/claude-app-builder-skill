# Next.js Static Site Template

Use for marketing, documentation, and content sites where most pages can be statically rendered.

## Priorities
- Semantic HTML and accessible navigation
- Metadata, canonical URLs, sitemap, and robots rules
- Optimized images and fonts
- Content model and editorial workflow
- Responsive layouts and Core Web Vitals

Avoid adding a database or authentication layer unless the requirements need one. Verify generated routes and metadata before deployment.
