# Project Template Selection

Choose one template matching the detected project type. Read only the selected template and adapt it to the user's constraints.

## Templates
- `nextjs-fullstack/TEMPLATE.md`: authenticated full-stack web product.
- `nextjs-saas/TEMPLATE.md`: subscription SaaS with billing integration.
- `nextjs-static/TEMPLATE.md`: static marketing or content site.
- `nuxt-app/TEMPLATE.md`: Vue/Nuxt application.
- `express-api/TEMPLATE.md`: Node.js REST API.
- `python-fastapi/TEMPLATE.md`: Python API.
- `react-native-app/TEMPLATE.md`: cross-platform mobile app.
- `flutter-app/TEMPLATE.md`: Flutter mobile app.
- `electron-desktop/TEMPLATE.md`: desktop app.
- `chrome-extension/TEMPLATE.md`: browser extension.
- `cli-tool/TEMPLATE.md`: command-line utility.
- `monorepo-turborepo/TEMPLATE.md`: multi-package monorepo.

Templates are architecture checklists, not blind copy-paste generators. Confirm current framework versions and official setup commands before scaffolding.
