# Express API Template

Use for a focused Node.js HTTP API.

## Structure
- `src/routes/`: route declarations
- `src/controllers/`: HTTP translation
- `src/services/`: application workflows
- `src/repositories/`: persistence
- `src/middleware/`: auth, validation, error handling
- `src/config/`: validated configuration
- `tests/`: unit and integration tests

Add request validation, authentication, authorization, rate limiting, structured logs, request IDs, graceful shutdown, and health endpoints. Keep secrets out of source control.
