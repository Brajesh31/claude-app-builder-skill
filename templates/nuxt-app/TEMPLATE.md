# Nuxt Application Template

Use for Vue applications that benefit from Nuxt routing, rendering, and server capabilities.

## Structure
- `pages/`: file-based routes
- `components/`: UI components
- `composables/`: reusable reactive logic
- `server/api/`: server endpoints
- `middleware/`: route-level concerns
- `layouts/`: shared page shells

Validate server inputs, keep secrets in private runtime configuration, and choose SSR, prerendering, or client rendering per route needs. Add tests for composables and critical user flows.
