# Flutter Application Template

Use for cross-platform apps built with Flutter and Dart.

## Structure
- `lib/app/`: app configuration and routing
- `lib/features/`: feature modules
- `lib/shared/`: reusable widgets and utilities
- `lib/data/`: API and persistence adapters
- `test/`: unit, widget, and integration tests

Choose state management based on complexity and team familiarity. Handle permissions, secure storage, offline behavior, accessibility, and platform-specific configuration. Run analyzer and tests before release.
